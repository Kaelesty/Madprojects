# 🎓 Madprojects

**Madprojects** — это интеллектуальная система управления жизненным циклом учебных проектов, объединяющая преподавателей и студентов в единой цифровой экосистеме.  
Платформа автоматизирует организацию, контроль и оценку учебных проектов, упрощая взаимодействие между всеми участниками образовательного процесса.

---

## 🚀 Основные возможности

- 🧩 **Управление проектами** — создание, планирование и сопровождение учебных проектов.  
- 👩‍🏫 **Интерактивное взаимодействие преподавателей и студентов** — назначение заданий, обратная связь, комментарии и оценки.  
- 📊 **Мониторинг прогресса** — визуализация выполнения задач, дедлайнов и статусов.  
- ⚙️ **Автоматизация** — интеграция с календарями и системами учёта, автоматическое формирование отчётов.  
- 🌐 **Кроссплатформенность** — в будущем проект будет доступен на Android и iOS через общее приложение на Kotlin Multiplatform.

---

## 🧠 Архитектура проекта

Проект разделён на два ключевых модуля:

### 🔸 Backend  
- Реализует REST API и бизнес-логику  
- Обрабатывает аутентификацию, хранение данных и управление пользователями  
- Использует **Ktor**, **PostgreSQL**, **Exposed ORM**

### 🔹 Мобильное приложение (Kotlin Multiplatform)  
- Находится в активной разработке  
- Планируется как кроссплатформенное решение для Android и iOS  
- Основано на **Kotlin Multiplatform (KMP)** и будет использовать общий код для бизнес-логики и сетевого слоя

# 🎓 Madprojects (English)

**Madprojects** is an intelligent lifecycle management system for academic projects, connecting teachers and students through a unified digital ecosystem.  
The platform automates organization, tracking, and evaluation of academic projects, simplifying communication and collaboration throughout the educational process.

---

## 🚀 Key Features

- 🧩 **Project Management** — create, plan, and manage academic projects.  
- 👩‍🏫 **Teacher–Student Interaction** — assign tasks, exchange feedback, and track progress.  
- 📊 **Progress Monitoring** — visualize project status, tasks, and deadlines.  
- ⚙️ **Automation** — integrates with calendars and course systems, auto-generates reports.  
- 🌐 **Cross‑platform** — a Kotlin Multiplatform mobile app for Android and iOS is planned for future development.

---

## 🧠 Architecture

The project consists of two main modules:

### 🔸 Backend  
- Implements REST API and business logic  
- Handles authentication, data storage, and user management  
- Built with **Ktor**, **PostgreSQL**, **Exposed ORM**

### 🔹 Mobile Application (Kotlin Multiplatform)  
- Currently under active development  
- Planned as a cross‑platform solution for Android and iOS  
- Based on **Kotlin Multiplatform (KMP)** with shared business logic and networking layer
